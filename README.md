# Entrega Akkü Studio Lab - Andrea Fernández
Este proyecto es una plataforma estratégica para gestión de clientes y servicios.

### Instrucciones de prueba:
1. **Inicio:** Entrar a `/` para ver el Dashboard.
2. **Consultas:** Entrar a `/consulta/` para cargar un nuevo prospecto.
3. **Servicios:** Entrar a `/nuevo-servicio/` para cargar un servicio.
4. **Cursos:** Entrar a `/nuevo-curso/` para cargar un curso.
5. **Buscador:** Entrar a `/buscar/` para filtrar en la base de datos.
